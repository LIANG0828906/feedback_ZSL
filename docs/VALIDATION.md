测试覆盖：

- 三 schema 严格字段映射、默认补齐痕迹、`E_SCHEMA` 路径/对象、`E_OVF`、`E_PARA`。
- v3→v2→v3 与 v3→v1→v3 坐标/序号/权重往返。
- 笔刷整图与分块一致、并发覆盖哈希一致、输入乱序不影响唯一合成次序。
- 连通域/孔洞/环宽/方向真值，`E_TOP` 与 `E_DIR` 域编号和实测值。
- 三版本各自三种执行路径逐像素一致。
- 编辑后精确失效、恢复路径与全量重算一致。
- 单笔故障隔离、失败状态保留、清障后重试与全量一致。
- SQLite 事务回滚、并发串行提交、重启恢复、内容/版本失配整体失效。
- 子进程不调用 `Close` 直接 `os.Exit(0)` 后，仅恢复已提交状态。
- HTTP 页面、工程 API、全部 PNG 端点、编辑接口、404 根路由隔离。

## 本地页面烟雾

命令：

```bash
go run ./cmd/maskqc serve \
  -data samples \
  -db state/demo.db \
  -addr 127.0.0.1:38080 \
  -parallel 4 \
  -queue 2
```

使用 `38080` 是因为共享开发机上 `8080` 已被其他无关进程占用。
