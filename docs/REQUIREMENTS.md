掩码质检口径目前只有一份需求草稿，代码一行未写；介入这项工作的开发机上只有一个刚创建的空目录，除已就绪的 Go 工具链外没有源码、样本与历史约定可继承。团队要在正式接入切图平台之前，先独立交付一套笔画方向与连通拓扑一致性核验工作台，既作为可集成的 Go 领域组件，也提供本地页面可重复演示与诊断的领域应用。图标图像、候选掩码、笔刷施工记录与解析真值全部由实现自带的确定性生成器按固定种子产出：图标含前景色块、与前景近色的背景渐变、半透明描边与嵌入式噪声，候选掩码刻意带有内缩、外溢与小空洞；施工记录按笔画声明栅格化顺序、起止像素、笔刷硬度与覆盖权重；真值给出各前景连通域的重心、面积、外接框、孔洞数量、像素级参考掩码与各边界段的期望方向类别。同一批工程以三个 schema 版本描述，版本差异体现在字段命名、笔画坐标的绝对与相对表达、覆盖权重的千分比与万分比刻度、笔刷硬度与方向类别编码的有无上。

任务环境与准备：
准备 Linux（WSL Ubuntu）与 Go 工具链，工作目录从空目录开始。
准备可访问的 Go 模块代理以获取 modernc.org/sqlite 与 database/sql 驱动依赖，并确保其可在离线缓存后重复构建。
准备本地 net/http 监听端口用于诊断页面，提供仓库内确定性样本与固定种子即可复现，无需外部服务或真实账号。

业务要求：
1. 实现本地确定性样本生成器与三版本图标工程的统一加载器：按固定种子产出多张不同分辨率图标图像、带内缩外溢与空洞的候选掩码、笔刷施工记录与真值清单；读取三个 schema 版本的描述，把字段命名、笔画坐标表达、覆盖权重刻度、笔刷硬度与方向类别编码统一映射为内部笔画模型并保留源版本标识；未知版本或必备字段缺失返回 E_SCHEMA 并指出字段路径与对象标识。
2. 实现版本升降级的显式转换规则与可追溯痕迹：低版本升级时按声明默认值补齐缺失的笔刷硬度、方向类别与合成次序字段，每次补齐记录字段路径、旧值与来源默认值；内部模型导出到低版本时，对无法表达的按笔画分组结构或方向类别生成 E_LOSSY 清单并记录降级处置方式，导出产物须能被对应版本加载器读回。
3. 实现笔画坐标表达与覆盖权重刻度的整型换算及往返一致：绝对像素与按笔画序号推导的偏移之间、千分比与万分比权重之间用整型运算按声明取舍方向处理余数并逐处记录截断位置与残差，全链路禁止浮点累积；同一笔画经高版本到低版本再回到高版本后起止坐标、笔序号与覆盖权重须完全一致，换算溢出返回 E_OVF 并给出字段与两个操作数。
4. 实现单笔栅格化与覆盖合成核心：按声明的笔刷硬度与覆盖权重把每笔栅格化为覆盖分量，再与候选掩码按 alpha 合成规则累加得到积算掩码；同一笔在相同参数下覆盖分量逐像素相同，不随分块完成顺序或线程调度改变；笔刷硬度越界或权重刻度超出允许集合返回 E_PARA 并给出字段名与合法范围。
5. 实现笔画合成次序的确定性裁决与最终掩码的连通拓扑及方向核验：同一组笔画在不同声明顺序下合成可能得到不同的中间掩码，须按施工记录声明的工序优先级与笔序号定义唯一合成次序，并逐分块记录参与笔序号与裁决依据；由积算掩码提取各前景连通域，计算重心、面积、外接框、描边环带宽度与孔洞数量并与真值逐域配对比对，同时按边界段法向与笔画行进方向判定方向一致性类别；孔洞或环带宽度超容差返回 E_TOP，方向类别与真值不符返回 E_DIR 并列出域编号与实测值。
6. 实现笔画与分块之间的依赖图及编辑后的精确失效传播：缓存键由分块输入内容哈希、笔画标识、合成次序版本、换算参数版本与上游缓存键共同决定，显式记录笔画、合成次序、拓扑与方向核验同下游分块产出之间的依赖；编辑某笔起止坐标、笔刷硬度或工序序号时仅将实际受影响分块及其下游标记失效，未受影响分块复用持久化结果并输出含笔画标识的失效清单。
7. 保证实时增量核验、断点恢复核验与一次性全量重算三条路径逐像素一致，并实现受限预算下的分块并行调度：三者对同一工程、同一编辑序列与同一参数须产出相同积算掩码、相同连通域统计、相同方向类别与相同分块提交序列，自动比对定位首个不一致分块编号与像素坐标；栅格化与分块累加在工作线程池并行时须限制最大并行度、每线程像素缓冲上限与待处理分块队列预算，预算耗尽时阻塞排队并记录排队原因与等待时长而非静默丢弃。
8. 实现基于 database/sql 与 modernc.org/sqlite 的笔画级原子检查点与异常隔离，并交付 net/http 本地诊断页面：每提交一个笔画在受影响分块上的覆盖分量，把该分量摘要、缓存键、内容哈希、换算残差摘要、合成次序版本与算法版本在单一事务中串行写入，写入不得交错且提交顺序稳定；重启加载时任一内容哈希或版本不匹配须整体判定失效并重算；单笔画内部异常只置该笔画为失败并允许重试且不污染其他笔画与已提交分块，进程被强制终止后只依据已提交状态恢复；页面展示候选掩码、积算掩码、逐笔覆盖分量、连通域统计与方向类别标注、失效传播示意及预算占用与排队明细。
