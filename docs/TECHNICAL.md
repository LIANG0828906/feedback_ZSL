# 技术设计说明

## 1. 定点化数值策略

所有小数量以整数定点表达，`SCALE = 1000`（`tacpath/fp.py`）：

- 移动代价：进入正交邻格 `cost*1000`，对角邻格 `cost*1414`
  （sqrt(2) 的定点近似）。代价累加是纯整数加法，累加误差恒为 0，
  不存在逐级放大的浮点偏差。
- 溢出边界：所有累加器以 `MAX_COST_FP = 2^62` 为明确上界，
  越界抛 `E_OVERFLOW`。
- 世界坐标：格心 `(x,y) -> (1000x+500, 1000y+500)`，与路径折线、
  推进轨迹同一精度。
- 朝向：毫弧度整数（`PI_MRAD = 3142`）。

## 2. 确定性搜索契约

`tacpath/search.py` 与生成器中的独立参考实现
（`tacpath/mapgen.py: reference_astar`）共同遵守同一契约：
邻域顺序 E,S,W,N,SE,SW,NW,NE；禁止切角；堆键 `(f, g, x, y)` 懒惰删除；
仅在严格更小的 g 时改写父指针。因此同一地图与起终点的搜索输出
（路径、代价、拐点）完全确定，并与解析真值零误差吻合。

启发式 `h = octile(dx,dy) * min_cost * wn // wd`：octile 距离乘最小
格代价是真实剩余代价的下界，权重 `wn/wd <= 1` 时不高估；`wn > wd`
在搜索前即以 `E_HEUR` 拒绝。整数向下取整只会进一步压低估计。

## 3. 路径平滑与拐点

- 视线检查用精确整数 DDA 超覆盖线（`supercover_line`），网格角穿越
  时同时覆盖两个正交格，平滑段不可能穿过不可通行格。
- 平滑容差 = 被跳过原始格到候选线段的最大偏离（定点），全部比较
  以整数叉积完成。容差收紧时可行跳段集合单调缩小，拐点数单调不减。
- 平滑代价按同一移动代价模型沿 Bresenham 行走格累加（通行性仍由超覆盖线保证），必然 >= 最小代价
  （平滑路径仍是合法路径）；代价差上界
  `cells_walked * max_cost * DIAG - min_cost` 仅由已观测定点参数推导，
  超界抛 `E_SMOOTH`。
- 拐点双读数：网格坐标（整数）与世界坐标（定点整数）。

## 4. 战术推进推演

位置是路径弧长 s 的纯函数（折线上整数插值），因此：
不越出折线、不跳段、不瞬移；朝向以转向速率上限追踪当前段方向，
拐点处不会瞬转。每 tick 记录
`(tick, x_fp, y_fp, heading_mrad, segment, s_fp)`。
步长/转向越界抛 `E_PARA`（`0 < step <= 100*SCALE`，
`0 < turn <= PI_MRAD`）。位置量化残差每 tick < 1 定点单位且不累积
（每 tick 由 s 重算）；不同帧率采样到同一弧长处的世界坐标偏差
上界为 2 定点单位（两次独立取整）。

## 5. 误差传播报告

四项统计（`tacpath/report.py`），上界只由已观测定点参数、邻域阶数
与步长量化单位推导：

| 统计 | 实测 | 上界 |
|---|---|---|
| 代价累加误差 | 与真值已知格逐项对照 | 0（纯整数累加） |
| 启发式偏差 | h(probe) - 真值剩余代价 | 0（构造即可采纳） |
| 平滑代价差 | 平滑代价 - 最小代价 | cells*max_cost*DIAG - min_cost |
| 推进量化残差 | 每 tick < 1 fp（微单位计量） | 1 fp/tick，不累积 |

任一项超界时报告标出具体格坐标或 tick 编号并抛 `E_BOUND`。

## 6. 检查点与断点恢复

- 搜索、平滑各为一个块，推进按折线段分块；每段完成并校验
  （位置在折线上）后，快照（中间状态、内容哈希、定点参数版本、
  算法版本）经 `tmp + os.replace` 原子写入，写锁保证串行不交错。
- 加载时地图内容哈希 / 参数版本 / 算法版本任一不匹配即删除整个
  快照并全量重算；段只可能来自同一份完全匹配的快照，禁止部分混用。
- 段内异常：该段标记失败并原地重试（默认 1 次），已完成段的
  检查点不受影响。
- 取消/强终止：只有已持久化的段可用于恢复；不承诺强终止后仍能
  产出完整误差报告；不以线程超时宣称失控任务已终止。

## 7. 三路径一致性

realtime / resume / recompute 使用同一确定性算法与同一分段驱动，
`compare_outputs` 逐格比对路径、比对拐点序列、逐 tick 比对轨迹，
首个不一致处以 `E_DIFF` 返回（格坐标或 tick 编号 + 所属段），
`replay_tick` / `replay_segment` 支持在该点重放复核。

## 8. 错误码

`E_SCHEMA` 地图字段/数值校验失败（含字段名）；`E_POINT` 起终点/
探针非法；`E_DECODE` 地图文件损坏；`E_HEUR` 启发式可能高估；
`E_SMOOTH` 平滑不变量违例；`E_PARA` 推进参数越界；`E_BOUND`
观测误差超出推导上界；`E_DIFF` 三路径输出不一致；
`E_OVERFLOW` 定点累加溢出；`E_CANCELLED` 取消边界；
`E_NOPATH` 不可达。

## 9. 实测验证结果（2026-11-23，Python 3.11.18 + NumPy 2.4.6）

- 4 张地图（16x12 / 31x24 / 64x48 / 48x40）共 8 对起终点：
  最小代价、标准路径长度、拐点坐标与解析真值零误差吻合；
  探针格最小累计代价零误差。
- 8 组 realtime / resume / recompute 三路径比对全部逐格、逐 tick
  一致；帧率偏差实测 0（上界 2 fp）。
- 误差报告四项统计全部无超界（violations = 0）。
- 28 个测试用例全部通过，覆盖全部错误码、检查点失效、段重试、
  E_DIFF 定位与重放。
