验收清单被先行拟定出来，而实现尚未开始：团队要在装有 Go 工具链的 Linux（WSL Ubuntu）开发机上，于尚未初始化的空目录里独立交付一套 TLS 握手并行探测与证书链校验调度内核，既作为可集成的 Go 领域组件，也提供本地可重复演示入口。当前目录没有源码、样本与历史约定，全部探测工程与解析真值均由实现自行编写的确定性生成器按固定种子产出，不依赖真实站点、账号或外部证书服务。同一份探测工程以三个 schema 版本描述同一内容：版本差异体现在字段命名、握手目标表达（扁平常量终结点表与按证书链分组嵌套树）、超时与探测周期单位（tick 与毫秒、秒与毫秒）、证书链深度与链校验预算的千分比与万分比刻度，以及可选握手水位与链固定标记字段的有无上。每份工程声明若干终结点（目标名、协议版本区间、密码套件集合、探测周期与超时、最大并行握手上限）、若干候选证书链（逐级证书摘要、签发者与被签发者关系、有效期区间），以及一批按逻辑时间排列的握手请求与证书链更新事件；生成器同时以解析构造记录真值：每个逻辑时刻各终结点的握手结论、证书链逐级校验结论与校验预算消耗、被门控拒绝的请求及其归因，真值是精度与判定观测的唯一来源。

任务环境与准备：
安装 Go 1.22 或以上版本，在 Linux（WSL Ubuntu）下可直接使用系统包管理器或官方压缩包安装，并用 go version 确认。
准备 SQLite 依赖：使用纯 Go 驱动（如 modernc.org/sqlite）或系统自带 libsqlite3，通过 go mod tidy 拉取依赖，保持离线可复现所需的本地模块缓存。
在空目录中执行 go mod init 初始化模块，不预置任何源码、样本与历史约定；确定性样本生成器与样本均在任务中由实现自行编写生成。
确认工作目录具备读写权限并可创建 SQLite 数据库文件；不依赖真实站点、外部证书服务、容器运行时或任何线上账号。
运行演示与验证命令统一为 go run 或 go test，退出码使用整数，业务错误以 E_xxx 符号出现在 JSON 或 stderr 中。

业务要求：
1. 实现覆盖三个 schema 版本的探测工程装载器，把字段命名、终结点扁平表与按证书链分组嵌套树、时间单位（tick 与毫秒、秒与毫秒）、预算刻度的千分比与万分比以及可选握手水位与链固定标记统一映射为内部探测模型，保证同一工程经三个版本装载后的终结点集合、候选链顺序与请求序列完全一致；版本无法识别或字段组合自相矛盾时返回稳定的 E_xxx 业务码与可定位上下文。
2. 实现按逻辑时间推进的握手请求判定与证书链逐级校验，覆盖签发者与被签发者关系、有效期区间与协议版本区间的联合判定，逐请求输出握手结论、所校验的链编号与逐级通过或失败原因；链中某级校验失败时其后各级不得判定为通过，同一时间换算在 tick 与毫秒下须得到同一有效或过期结论，结果与真值逐请求逐级一致。
3. 实现证书链校验预算与并行握手上限的双约束调度，预算消耗在千分比与万分比刻度间换算后须得到同一准入结论，超出预算或并行上限的握手须进入等待队列并记录被违反的约束编号与排队序号；因排队与释放存在跨时刻传导，须输出每个等待项最终准入时刻，且任何调度顺序都不改变准入集合。
4. 实现握手期资源冻结与门控回退：某终结点在链更新未提交或握手未完成的时间窗内，其证书链校验预算须冻结，冻结期到达的请求不得计入已用预算而应进入等待队列，解冻只发生在链更新提交之后；被门控拒绝的请求须输出归因类别（预算冻结、链校验失败、并行上限耗尽）与回退到上一有效链的依据。
5. 实现握手中断后的回退与续做：一次握手或链更新在提交点前被打断时须回退到最近已提交状态，已完成的分步校验须从最近提交点续做而非整体重来，恢复后同一请求不得同时计入两条链的预算占用；强制终止后的恢复只能依赖已持久化状态，不得承诺生成退出报告。
6. 在声明的线程预算与每终结点待探测请求缓冲上限下并行推进多终结点的握手判定与链校验，缓冲或线程预算耗尽时须产生确定的可观测背压结果而非越界分配或静默丢弃，同时记录每终结点实际耗时观测值用于诊断；任何并发度、终结点调度顺序与提交批次都不改变握手结论、逐级校验结论与门控归因。
7. 把已提交的逻辑时刻序号、各终结点已用校验预算、冻结集合、等待队列与链状态按先落终结点与链状态再更新全局序号的次序写入 SQLite 检查点，使进程在任一提交点被强制终止后重启都不会读到未完成时刻；恢复只接受版本匹配的检查点，整份工程快照被替换时须识别版本变化并丢弃过期判定缓存。
8. 实现终结点、候选链与握手请求编辑后的增量失效：改动某链的有效期、签发关系、探测周期或追加减删请求时，只重算依赖链经过该终结点或链的后续时刻区间与门控判定，未受影响区间必须复用缓存结果并输出每处结果所依据的失效来源；增量结果须与一次性全量重算逐请求逐级一致，并通过输入或参数注入越界预算刻度、成环证书链、截断检查点与版本不匹配快照验证异常链路。
