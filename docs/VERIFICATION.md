# Acceptance Verification

Validation was performed locally on the generated deterministic 64³ sample.
No Docker/container environment and no external target access were used.

```text

OK
```

Logs:

- `artifacts/test_linux.log`
- `artifacts/test_windows.log`

Covered:

- file header/payload CRC and sample hashes,
- non-silent window/spacing map rebuild and max absolute delta,
- TF validation, interval bounds, invalid edit preserving old LUT,
- same-state byte determinism and content hash,
- threshold-based untrusted marking,
- boundary and zero-gradient normals,
- lighting drift pass / `E_LIGHT_DRIFT`,
- float/fixed switching, semantics and pixel-difference statistics,
- snapshot roundtrip/resume, corrupted/missing/stale snapshots,
- restore from another volume without partial mutation,
- `E_BUSY` duplicate submission,
- offscreen buffer release and last-good retention,
- Windows/Linux PyQt5 window and QImage smoke.

## Precision Comparison

Same 80×80 view, same LUT control points:

| Metric | Float | Fixed Q12 |
| --- | ---: | ---: |
| max propagated error | `5.234059092353972e-05` | `0.003092477472439918` |
| untrusted pixels | `0` | `740 / 6400` |
| trusted fraction | `1.0` | `0.884375` |
| status | `converged` | `low_confidence` |

Display buffer difference:

```text
mean abs pixel diff = 12.753359375
RMS                 = 46.78675193096866
max                 = 255
changed fraction    = 0.13640625
semantics unchanged = true
```

The large `max=255` difference is expected: fixed-path pixels whose propagated
error exceeds the threshold are intentionally masked to zero instead of shown
as reliable color.

## Error-Code Replay

`scripts/verify_acceptance.py` produced:

| Scenario | Expected | Actual |
| --- | --- | --- |
| non-monotonic / duplicate / out-of-range / NaN TF | `E_TF_INVALID` | `E_TF_INVALID` |
| precision mode `int8` | `E_MODE_INVALID` | `E_MODE_INVALID` |
| lighting tolerance below measured drift | `E_LIGHT_DRIFT` | `E_LIGHT_DRIFT` |
| changed RGBA bytes with updated wrapper hash | `E_SNAPSHOT_INVALID` | `E_SNAPSHOT_INVALID` |
| truncated snapshot | `E_SNAPSHOT_INVALID` | `E_SNAPSHOT_INVALID` |
| missing snapshot field | `E_SNAPSHOT_INVALID` | `E_SNAPSHOT_INVALID` |
| changed state without state-hash update | `E_SNAPSHOT_STALE` | `E_SNAPSHOT_STALE` |
| changed view/step with stale version | `E_SNAPSHOT_STALE` | `E_SNAPSHOT_STALE` |
| simultaneous render submission | `E_BUSY` | `E_BUSY` (unit test) |

Snapshot roundtrip:

```text
save -> load -> change step -> restore -> resume_render
content hash matches original: true
```
