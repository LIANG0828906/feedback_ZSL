# 设计与确定性约束

## 渲染管线

1. `Scene` 解析并校验 DUSTVOL1 容器、相机、介质、父级包含关系和密度块。
2. `build_chunk_table` 以行优先顺序生成稳定提交序号 `c0000...`。
3. 计划阶段用与正式渲染相同的路径计算主采样数和阴影采样数。
4. 预算策略在执行前决定等待、降级或拒绝，并写入确定性 JSONL 轨迹。
5. 每个像素从相机中心发射中心采样射线，按所有介质边界切成有序分段。
6. 在每个分段内以全局射线参数为锚点采样，不读取分块原点，因此相邻分块不存在
   相位突变。
7. 密度越高，步长按 `base / (1 + gain * density)` 收缩，并限制在 min/max 之间。
8. 每个主采样执行固定数量的阴影采样，估计方向光可见性，累积 RGB 散射和标量
   透射率。
9. 分块结果按表拼接；可选整屏单块真值渲染用于接缝比较。

## 预算与并行轨迹

任务提交顺序固定。实际工作可以跨分块并行，轨迹中的 worker 分配由采样成本确定：
同一时刻按提交序号启动可运行任务，完成顺序由纯采样成本推导。这样并行度来自配置，
但轨迹不受操作系统线程调度或系统时间影响。超预算任务不启动，先进入等待集合并
记录 `budget_wait`；降级成功后记录 `budget_degraded`。

## 接缝

每个像素的采样相位只依赖场景、配置和全局像素坐标，不依赖它属于哪个分块。接缝
校验把分块结果与整屏单块结果逐像素比较，同时检查 RGB 散射和透射率。超差时返回
`E_SEAM_UNRESOLVED`，错误详情包含接缝像素、所在分块和相邻分块对。

## 精度

`float` 路径直接累积双精度中间量并输出 `float32`。`fixed` 路径在每次散射、透射率
和颜色更新时量化到 Q18 定点网格。比较模式分别渲染两条路径，输出 max、mean、
p95、RMS、散射/透射率最大偏差、误差图哈希和保守上界。

## 增量失效

- 相机或光源变化：无法证明局部无影响，保守全帧重渲。
- 介质参数变化：投影变化介质的包围盒，重渲覆盖的分块。
- 密度块变化：投影块本身，并把块沿反光方向扫掠 `shadow_distance` 后与使用该密度
  场的介质包围盒求交，覆盖可能的阴影依赖。
- 缓存分块按内容哈希复用，所有重渲完成后由 `AtomicPreviewBuffer` 一次替换整帧；
  替换前读取者仍看到旧版本。

## 快照

快照记录场景哈希、密度版本、配置指纹、精度、预算、分块表、已完成索引、每块 RGB
与透射率、内容哈希和顺序哈希链。保存先写同目录临时文件，`fsync` 后
`os.replace` 原子重命名。恢复验证快照总哈希、配置/场景/密度版本、块尺寸、内容
哈希和链式哈希；任何断链或字段缺失返回 `E_RECOVERY_INVALID`。恢复只渲染缺失
分块，已完成块不重复计算。

## 确定性

- 不使用当前时间、随机数或网络资源。
- 所有 JSON 使用排序键和紧凑分隔符。
- 轨迹序号、分块 ID、提交顺序和 worker 分配均为纯函数。
- 固定输入下图像与透射率数组按小端 `float32` 连续字节计算 SHA-256。
