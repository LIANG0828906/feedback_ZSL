# 五层剪纸屏风灯箱离线软光栅验证组件 — 技术说明

## 1. 范围与依赖

纯 Python 离线实现，仅依赖 NumPy 与 Pillow，不使用 GPU、外部素材或网络。
所有几何、镂空、纤维纹理、软阴影采样均由场景 JSON 中的整数种子确定性构造。

模块划分：

- `paperlightbox/rng.py`：固定位宽 PCG32 与三整数坐标格点哈希、三线性值噪声。
- `paperlightbox/texture.py`：确定性镂空掩码与纤维斑驳场（采样器与渲染端共用）。
- `paperlightbox/geometry.py`：平面网格 O(1) 光线求交、通用 Moller–Trumbore 求交、
  点光源透视投影、点-纸面判定。
- `paperlightbox/scene.py`：JSON 加载、结构化校验、与输入顺序无关的场景摘要。
- `paperlightbox/raster.py`：相机射线、区域光源软阴影、逐片元透射/散射着色、
  预乘 Alpha 由内向外合成。
- `paperlightbox/snapshot.py`：原子分块快照、摘要校验、损坏整体丢弃。
- `paperlightbox/pipeline.py`：分块调度、恢复、探针半影测量、PNG/深度输出。
- `paperlightbox/report.py`：稳定字段统计报告与逐像素差异报告。
- `paperlightbox/cli.py`：`generate` / `render` / `compare` 子命令与信号处理。

## 2. 业务要求到实现的对应关系

### 2.1 几何与材质校验（要求 1）

`scene.validate_scene` 在任何像素计算前完成校验，失败抛出 `SceneError`，
CLI 以错误码整数非零退出并输出结构化 JSON（含 `error_code`、`reason`，
可定位时含 `layer`），不写出任何图像。错误码定义在 `errors.ERROR_CODES`：
索引越界=2、退化三角形=3、透光率越界=4、层序号重复/缺失=5、光源落入纸面=6、
相机非法=7、光源非法=8、分块/采样非法=9、镂空掩码与种子重算不一致=10。

### 2.2 确定性纤维与镂空（要求 2）

- 镂空以网格单元为最小粒度，随机游走生成连通斑，单元的两个三角形同时标记，
  因此镂空边缘与网格边严格对齐，不会产生亚三角形裂缝。
- 渲染端用同一种子重算掩码并与 JSON 中的 `holes` 比对，不一致即错误码 10。
- 纤维场是世界坐标 + 层种子的纯函数（两层值噪声八度叠加），与遍历顺序、
  全局随机状态无关；同时调制透光率与散射颜色，使同色不同种子的纸面可区分。

### 2.3 逐层透射与散射（要求 3）

每个可见片元按入射角、纤维调制后的有效透光率计算透过光，叠加纤维染色的
Lambert 漫反射与恒定环境底光；通过单调软膝响应 `x/(1+x)` 保证任何通道严格
小于 1，内层不发白、外层保留可辨色相。层按声明的 `index` 由内向外排序后做
预乘 Alpha over 合成，与输入列表顺序无关（有专门测试）。

### 2.4 层间镂空投影（要求 4）

对外层每个着色点，从点光源向该点发射阴影射线，只允许更小序号（更内层）遮挡；
射线命中镂空或射出纸面矩形都按无遮挡处理，因此投影超出纸面时不会产生硬黑边。
空气层厚度改变几何平面间距，透视投影落点随之偏移（报告与对照场景均有体现）。

### 2.5 软阴影半影（要求 5）

点光源带半径，按场景声明的 `sample_density` 做金角盘状采样；盘样本遮挡比例
即软阴影因子。半影宽度随空气层厚度增加而变宽。报告 `soft_shadow_probes` 给出
每层固定镂空边界投影线上的逐采样点亮度（`shadow_luminance`）、采样坐标与
`penumbra_width_world`，同密度重复运行完全一致。

### 2.6 分块渲染与可恢复快照（要求 6）

图像按 `tile_width/tile_height` 行主序分块。每块先写临时 `.npz` 再原子替换，
最后原子重写 `manifest.json`（含场景摘要、图像尺寸、每块 RGBA/深度摘要）。
重启仅信任通过摘要校验的已提交块；场景摘要不一致或快照任何部分损坏时，
整个快照目录被清空并从零重算，绝不沿用旧块偏移或旧场景数据。

### 2.7 恢复逐像素一致（要求 7）

所有随机性来自整数种子与像素坐标，分块本身无跨块副作用，因此续算结果与一次性
渲染天然一致。`compare` 子命令同时比对 8-bit RGBA（PNG）与 float32 光学深度
（`optical_depth.npy`）；不一致时输出含分块编号、像素坐标与 RGBA 通道差异的
结构化报告并以退出码 12 结束。优雅中断（停止文件或 SIGTERM/SIGINT）完成当前块、
写 `recovery_report.json` 并以 0 退出；SIGKILL 不保证退出报告，但已原子提交的
块仍可在重启后续算。

### 2.8 稳定统计报告（要求 8）

`report.json` 字段顺序由 `sort_keys` 固定，不含时间戳与绝对路径。包含每层
可见片元数、加权平均透光率、镂空三角形数与连通斑数、软阴影采样点数、分块完成
情况、每块颜色摘要、图像/深度 SHA-256、恢复次数。透光率为片元加权平均，
分块均值可直接由最终 RGBA 复算（报告内 `recomputed_tile_mean_rgba`）。

## 3. 光学深度定义

逐像素光学深度为该视线穿过的所有纸面片元的
`-log(effective_transmittance)` 之和，float32 存盘，用于恢复一致性核验。

## 4. Windows 本地运行

```
py -m pip install -r requirements.txt
py run_demo.py
py -m unittest discover -s tests -v
```

Windows 无 SIGTERM 语义时使用 `--stop-file` 协作式中断（创建文件即在下一块
边界停止），行为与 POSIX 信号路径一致。
