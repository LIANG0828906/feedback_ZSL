# 触觉事件通道合并与包络量化内核 — 技术说明

仅依赖 Go 标准库（Go 1.22+），无外部网络依赖、无容器。所有服务只绑定 `127.0.0.1`。

## 目录结构

| 路径 | 职责 |
| --- | --- |
| `cmd/haptic` | 本地入口：样本生成、三路径流水线、故障注入、诊断界面 |
| `internal/sample` | 固定种子（`Seed=20261124`）确定性样本生成器，落盘 `manifest.json`/`events.json` |
| `internal/validate` | 事件流与能力清单加载校验，输出带帧号/通道/字段名的业务错误码 |
| `internal/synth` | 通道仲裁、包络叠加、24bit→16bit 定点量化、有界并发调度器 |
| `internal/packetize` | 确定性切包、二进制编码/哈希、依赖图与精确失效传播、本地违规检查 |
| `internal/store` | 包状态机与文件检查点（原子写、串行提交、版本/哈希校验） |
| `internal/paths` | 实时 / 断点恢复 / 持久化全量重放三路径与逐采样自动比对 |
| `internal/device` | 回环模拟设备服务、异常注入、回显对齐与设备侧/内核侧异常分类 |
| `internal/diag` | 本地 HTTP 诊断界面（事件时间轴、曲线、包序列、对齐明细、重试） |

## 确定性设计要点

- 全程整数/定点运算，无浮点；模板电平用千分比 + 整型线性插值。
- 内部 24bit 定点累加（`FixedOne=1<<24`），输出饱和到 16bit（`-32768..32767`），
  每个采样点记录参与事件集合、叠加权重、饱和前累加值与量化残差。
- 所有 map 输出在落盘/编码前按键或事件 ID 稳定排序；事件按（帧、帧内序号、ID）仲裁。
- 包编码为固定大端字节布局（魔数 `HPK1` + 定长头 + 16bit 采样序列），
  重复编码逐字节一致，内容哈希为编码字节的 SHA-256。
- 切包按通道内网格偏移首尾相接，全局提交顺序按“通道内包序号轮询、再按通道”稳定编号。

## 仲裁规则

- 生效中事件带 `no_interrupt` 且新来事件优先级不高于它：新来者 `dropped`。
- 否则新来事件优先级不低于生效事件即接管，被接管事件记 `replaced`。
- 事件过模板生效期自动退出；同网格多事件按到达顺序与优先级得到唯一结论。

## 错误码

| 码 | 含义 | 侧 |
| --- | --- | --- |
| `E_ORDER` | 帧序/帧内序号非单调或最小事件间隔违规 | 校验 |
| `E_CHAN` | 通道越界 | 校验 |
| `E_TPL` | 模板引用缺失/模板配置问题 | 校验 |
| `E_PARA` | 量化单位、每包采样点数、缺失字段等参数非法 | 校验 |
| `E_STATE` | 状态机非法迁移（原状态保持不变） | 内核 |
| `E_DIFF` | 多路径结果不一致，含首个采样偏移/包序号与两侧取值 | 比对 |
| `E_MISS`/`E_DUP`/`E_TIMEOUT` | 设备侧缺包/重发/超时 | 设备 |
| `E_LOCAL` | 内核侧违规（采样点超限、时序越窗、边界不首尾相接、回显采样不符） | 内核 |
| `E_STORAGE` | 检查点读写失败 | 存储 |

设备侧异常与 `E_LOCAL` 在内核侧严格分栏，诊断界面与对齐报告均带 `side=device|kernel`。

## 状态机与检查点

- 合法迁移：`pending → quantizing → sliced → committed`；
  任意状态可 `→ failed`，`quantizing/failed → pending` 作为重试入口；`committed` 冻结。
- 每个窗口经临时文件 + `rename` 原子落盘，目录级互斥锁保证写入串行不交错。
- 重启加载逐包复核内容哈希、窗口整体指纹、能力参数版本与算法版本；
  任一不匹配或快照为空，整体作废并走全量重放。

## 三条执行路径

1. `realtime`：有界工作池并行合成 → 确定性切包 → 串行窗口提交。
2. `resume`：加载独立 `resume` 快照；有效则复用持久化包序列，无效则作废后全量重算并重新提交。
3. `replay`：严格只读 `replay` 快照中的持久化决策重建包序列，不重新做事件仲裁。

比对器逐采样点比较曲线、逐包比较切分边界与编码字节；不一致返回 `E_DIFF`，
并给出两路径名称、通道、网格偏移、包序号、两侧取值与逻辑时刻。

## 并发与资源边界

- 工作池大小由 `--workers` 限定；在途任务信号量满时提交方阻塞排队，不丢样。
- 每通道采样缓冲超过 `MaxBufferFrames` 记录背压事件（原因 `sample-buffer-limit-queue`）。
- 跨包提交与检查点写入始终串行，包提交顺序与单线程模式完全一致，`-race` 测试通过。

## 运行方式

```bash
go run ./cmd/haptic --no-http          # 终端验收，不启动界面
go run ./cmd/haptic                    # 启动后访问输出的 127.0.0.1 地址
go test ./...                          # 全部单元/集成测试
go build -o haptic ./cmd/haptic        # 构建本地二进制
```

常用参数：`--data`、`--checkpoints`、`--workers`、
`--fault-miss`、`--fault-dup`、`--fault-timeout`（逗号分隔的包序号）。
诊断界面 `POST /api/retry` 支持在页面上重新注入故障并对齐。
