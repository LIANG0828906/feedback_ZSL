# Architecture

## 1. Design goal

The workbench treats the casting session as a deterministic replicated state machine. Inputs are the generated sample, anomaly profile, engine configuration, and user state transitions. Outputs are ordered frame results, input replay results, phase events, desktop state, and a replay log. Wall-clock time is not part of protocol semantics; ordering uses sample logical timestamps and stable tie-break priorities.

## 2. Layering

```text
PySide6 UI
  ├─ MirrorView / PhaseTimeline / FragmentStrip / InputTimeline
  ├─ PlaybackWorker (QThread)
  └─ PathComparisonWorker (QThread)
            │
SessionEngine ── state machine, ordered commit, checkpoints
  ├─ renderer ── deterministic RGBA frame
  ├─ protocol ── frame encoding / 50-byte media header
  ├─ reassembly ── fragment map / CRC / missing detection
  ├─ desktop ── coordinate mapping / input mutation
  ├─ loopback ── UDP relay on 127.0.0.1
  └─ compare ── three-path field-level diff
```

The core has no Qt dependency and is exercised directly by tests and CLI.

## 3. Determinism

1. `sample_session.json` is generated by `samplegen.py` with fixed seed `424242`.
2. Frame pixels depend only on scene JSON, negotiated dimensions, and desktop modifiers.
3. Media compression is `zlib` with fixed level selected by codec profile.
4. Timeline ordering is `(timestamp_ms, priority, source_index)`; phase actions precede frames and frames precede inputs at equal timestamps.
5. Reassembly sorts by fragment index; physical arrival order only contributes `E_ORDER` diagnostics.
6. Input replay is ordered by input sequence; duplicate/stale sequences are rejected before mutation.
7. Checkpoints store complete replayable state. Recovery never replays already committed events.
8. Results do not depend on thread scheduling, network timing, or wall-clock time.

## 4. State machine

| State | Meaning |
|---|---|
| `negotiating` | capability intersection being resolved |
| `mirroring` | frames and inputs may commit |
| `paused` | transition valid but data events return `E_STATE` |
| `reconnecting` | connection rebuild phase |
| `disconnected` | terminal |

Legal edges are encoded in `models.LEGAL_TRANSITIONS`. A rejected transition creates a `PhaseEvent(ok=False, code="E_STATE")` and does not mutate counters. Public user operations raise `StateError`; timeline script transitions are logged and skipped.

## 5. Capability negotiation

Each device declares codec tiers, maximum width/height, maximum FPS, and input-backchannel support. The intersection resolves to the highest common codec rank. Output aspect ratio is preserved while fitting inside both devices' limits. FPS is the minimum of declared, sender, and receiver limits. If `requires_input_backchannel` is true, both sides must support input. Unsatisfied items are returned in `E_NEGO.details.items`.

## 6. Media wire format

50-byte big-endian header:

| Offset | Type | Field |
|---:|---|---|
| 0 | `4s` | magic `SCWB` |
| 4 | `B` | wire version |
| 5 | `B` | flags |
| 6 | `16s` | SHA-256(session_id) first 16 bytes |
| 22 | `I` | frame sequence |
| 26 | `H` | fragment index |
| 28 | `H` | fragment count |
| 30 | `Q` | logical timestamp in milliseconds |
| 38 | `I` | payload length |
| 42 | `I` | payload CRC32 |
| 46 | `I` | whole compressed frame CRC32 |

Payload data is `zlib(RGBA8888)`, split using the negotiated profile's fragment size. Reassembly validates all fragment indices, consistent frame metadata, payload CRC per fragment, whole-frame CRC, and decompressed byte count. Out-of-order fragments are accepted. Missing fragments trigger a finite retransmission loop. If still missing, a deterministic marker frame is committed, preserving ordered progress and `frames_sent == frames_reassembled`.

## 7. Input backchannel

The receiver wraps each event as canonical JSON with protocol version, session id, event payload, and SHA-256 of the canonical event. It travels over the same local UDP relay.

```text
mapped = floor(source_coordinate * negotiated_size / declared_size)
mapped = clamp(mapped, 0, negotiated_size - 1)
```

Every axis whose direct mapping fell outside the target is recorded in `clip_trace` with original value, raw mapped value, clipped value, and reason. Drag records both endpoints. Input replay is idempotent: sequence ids are tracked in the checkpoint and duplicate/stale events return `E_DUP` without desktop mutation.

## 8. Checkpoint transaction

Checkpoint payload includes protocol version, session id, content hash, capabilities hash, phase, timeline index, negotiation, runtime tier, retry limit, complete frame results with fragment status, complete input results and seen sequence set, desktop model, phase log, counters, last image digest/data, capability marker, and generation count.

```text
canonical(payload) -> SHA-256(payload_sha256)
write(temp) -> flush -> fsync -> os.replace(checkpoint.json) -> fsync(dir)
```

A process-local `RLock` serializes writes. On load, format version, wire protocol version, session id, content hash, capabilities hash, and payload digest are checked. A single mismatch moves the whole file to `checkpoint.invalid.json` and starts at `negotiating`; partial mixing is impossible.

## 9. Three execution paths

- **Realtime**: all actions in logical order.
- **Recovery**: run to a committed boundary, write a checkpoint, destroy the engine, load the snapshot in a new engine, continue from `timeline_index`.
- **Replay**: run the same sample and configuration in a fresh engine.

`compare.py` checks ordered frames, then inputs, then final phase, desktop state, and phase events. It reports the first differing component, index, field, left/right values, and owning phase. Any difference is `E_DIFF`.

## 10. Concurrency and resource limits

- UI playback and comparison execute in QThreads.
- Rendering/encoding tasks use `BoundedExecutor(max_workers=2, max_pending=8)`.
- `BoundedExecutor` rejects submission when the pending buffer is full.
- A renderer/encoder exception is isolated and retried once; a persistent failure marks only that frame failed and leaves the last committed mirror image intact.
- Engine `RLock` serializes frame commit, input commit, state transition, snapshot creation, and checkpoint bookkeeping.
- Checkpoint manager has its own lock so concurrent saves cannot interleave.
- Timeline order is never derived from worker completion order.

## 11. Log completeness

The NDJSON log writes a header, fsynced event lines, and a final `footer(complete=true)` only after clean completion and result export. If the process is killed or the user stops before completion, the file has no footer. `inspect_replay_log` therefore reports `partial`, the only valid claim after forced termination.
