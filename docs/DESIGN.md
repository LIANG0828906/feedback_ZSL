# 设计说明

## 1. 数据流

```text
固定种子生成器
  ├─ scene.json：深度网格 / 点光 / 聚光 / 面积光 / 介质 / 相机
  ├─ truth.json：全屏体积光真值 + 探针透射率/散射
  └─ manifest.json：源内容哈希
        │
        ▼
加载器：E_SCHEMA / E_REF / E_PARA / E_DECODE + 覆盖校验 + 内容哈希
        │
        ▼
引擎：依赖覆盖 → 失效集 → 稳定批次 → 线程池光线步进
        │                              │
        │                              ├─ 深度网格线段遮挡
        │                              ├─ 闭式介质透射率
        │                              ├─ 光源核 + HG 相函数
        │                              └─ 逐块 RGB / T / scatter / composite
        ▼
SQLite：manifest + batches + blocks + block_history
        │
        ▼
Wails 诊断视图 / headless verify
```

## 2. 确定性

分块结果只由以下输入决定：

- 场景内容哈希与各依赖版本；
- 有效渲染参数 `step/jitter/jitter_samples/camera`；
- 算法版本；
- 分块坐标。

线程数、缓冲槽、批大小、调度顺序不进入渲染参数版本，也不进入结果摘要。抖动使用 `seed + camera + pixel + sample index` 的确定性哈希，不共享可变随机数发生器。

## 3. 阴影与介质

深度网格每个单元是沿网格法线偏移的矩形平面片。阴影射线与每个单元的平面求交，并检查交点的 UV 是否落在该单元内。所有引用网格的遮挡取布尔 OR。

样本到相机的介质透射率：

```text
T(t) = exp(-sigma_t * t)
```

单次散射：

```text
L_s = integral_0^far T(t) * sigma_s *
      sum_light L_light(P(t)) * HG(dot(view, dirToLight), g_eff) * V(P(t), light) dt
```

`g_eff = 0.75 * light.anisotropy + 0.25 * medium.phase_g`。该组合在 UI 和真值生成器中使用同一构造，便于同时解释逐光源各向异性与介质基准相函数。

## 4. 真值路径

参考路径 `internal/volume/reference.go` 不调用 `RenderBlock`：

- 透射率用闭式指数；
- 单次散射在场景解析场上执行独立 Simpson 参考积分；
- 生成器将结果写入 `truth.json`，加载器只接受完整屏幕覆盖；
- 验证只把渲染结果与清单比较，不从渲染结果反向生成真值。

当前样本的声明容差：

```json
{
  "transmittance_abs": 0.00002,
  "scatter_abs": 0.004,
  "pixel_abs": 0.004,
  "relative": 0.002
}
```

## 5. 依赖与失效

光源影响范围按活动相机逐像素光线与光源支持体积求交（点/面积用支持球，聚光叠加圆锥二次式）。影响范围是分块集合，不依赖遍历顺序。

每个块还记录几何依赖：

- 对覆盖该块的光源，加入其引用的全部遮挡体；
- 对任一像素射线实际命中的基础几何，加入该网格；
- 几何依赖版本是“块依赖网格 ID → 网格哈希”的规范 JSON 哈希。

因此：

- 光源编辑只影响旧/新覆盖块；
- 介质编辑影响全部分块；
- 几何编辑只影响依赖该网格的块；
- 每个体积失效块生成一个下游 blend 失效项，深度为 1；
- 无失效块直接复用持久化缓存。

## 6. 批次与原子性

失效块按稳定顺序排序，按 `batch_size` 分批。每批：

1. 线程池并行计算，每线程受 `max_samples_per_thread` 样本缓冲限制；
2. 共享 `buffer_slots` 闸门；首次无槽时记录 `buffer_wait` 事件并阻塞排队；
3. 任一块 panic/错误只标记该块失败，包含失败块的批次不提交；
4. 成功的整批记录在单个 SQLite 事务中写入；
5. 事务提交后，在单锁内一次性替换内存批次；
6. 旧块值写入 `block_history`，不会被静默覆盖。

## 7. 预览误差上界

上界只使用观测到的有效参数与场景参数：

```text
DeltaT * sigma_s,max *
sum_light(I_light,max * phaseMax(g_eff)) *
integral_0^far exp(-sigma_t,min * t) dt
```

其中 `DeltaT`、抖动样本数、光源数量和消光/散射系数均来自实际运行参数。上界不使用 truth 清单。实测中降质预览最大像素差显著小于该保守上界。

## 8. 测试矩阵

- 加载错误：缺字段 `E_SCHEMA`、缺遮挡体 `E_REF`、负系数 `E_PARA`、坏深度网格 `E_DECODE`、真值缺像素。
- 渲染：分块确定性、参数快照、真值全屏/探针容差。
- 失效：点光/聚光/介质/几何编辑后续算块数与复用块数。
- 一致性：增量缓存 vs 空缓存全量；逐块摘要、像素、统计、混合像素。
- 比对定位：人为注入单像素差异，验证 `E_DIFF` 的分块/像素/item/左右值。
- 并发：不同线程数/缓冲槽/批大小输出一致；单槽四线程记录等待事件。
- 持久化：暂停后重启恢复、续跑、参数版本失配整体作废、并发提交批次号稳定、历史归档。
- 路径一致：预览同参数=全量；降质预览在上界内；断点续跑=全量。
