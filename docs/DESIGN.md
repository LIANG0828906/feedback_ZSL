# 赛事直播本地素材审看系统 — 技术说明

## 1. 环境与运行

- Python 3.12（实测 3.12.16），依赖见 `requirements.txt`：`numpy 2.5.5`、
  `PySide6 6.12.0`、`pytest 9.2.0`。
- 无显示环境（Linux/WSL、CI）使用脚本化入口：
  `QT_QPA_PLATFORM=offscreen python -m mediaaudit.cli --work-dir ./work --sample stereo_48k`
- Windows 桌面会话直接启动 Qt 窗口：`python -m mediaaudit.gui`。
- 全程本地确定性实现，不访问网络、不依赖真实编解码库。

## 2. 统一整数时基（要求 1）

主时基为整数微秒（`TICKS_PER_SECOND=1_000_000`），样本索引为源采样率下
的整数样本号。样本↔微秒通过 `fractions.Fraction` 精确换算，除不尽时向下
取整，杜绝浮点漂移。非法位深/声道/采样率、头与数据长度矛盾、帧时刻非
严格单调递增均抛 `E_SOURCE_INVALID`，`AuditError.location` 定位首个非法
字段，如 `("frames","frames[2]","time_s")`。

## 3. 参数版本模型（要求 2）

`TierParams`（目标采样率、Q8 增益、量化刻度、切片跨度）内容经排序键紧凑
JSON 计算 SHA-256 内容哈希。`ParameterStore` 维护每档单调递增版本，记录
哈希与来源（`new`/`rollback`）。普通提交内容相同则去重返回既有版本号；
回退始终生成新版本并以 `rolled_back_from` 指向历史版本，不改写历史。

## 4. 切片生成与内容哈希（要求 3）

重采样为相位对齐线性插值，增益为 Q8 定点乘法加饱和，边界由共享微秒时基
与量化刻度整除得到。内容哈希仅对切片内容序列化载荷计算，载荷不含墙钟
时间、文件路径与参数版本号，因此同参数回退后同一切片哈希逐字节一致。

## 5. 依赖图谱与增量重算（要求 4）

图谱节点含源时基、三个参数组件（重采样/增益/量化）与切片；边记录切片对
源与参数组件的依赖。参数变化后从变更组件出发判定受影响切片：仅增益/重
采样变化时保留网格、重算音频；量化组件或切片数变化时无法证明边界不变，
全部保守重算并在 `plan.reasons` 标注原因；无法证明未受影响的切片同样保守
重算。每次结构变化递增 `graph_version`。

## 6. 回退失效与陈旧缓存拒绝（要求 5）

回退生成新版本后，按历史参数重算每片，并与回退目标版本的磁盘缓存哈希
比对。一致才允许复用，不一致即拒绝复用、降级重算，并在轨迹与结果中记录
首个不一致切片序号及 `cached_hash`/`expected_hash` 双侧哈希。

## 7. 跨档起止样本一致性（要求 6）

以两档所有切片边界的并集划分共享微秒窗口，逐窗比较两侧源起止样本与相对
偏移量。首个不一致窗口抛 `E_SPAN_MISMATCH`，`details` 给出受牵连档位、
切片清单与偏移量。

## 8. 原子提交与断点恢复（要求 7）

切片先写 `.tmp` 再 `os.replace` 原子重命名；清单 `manifest.jsonl` 每行携带
`prev_hash`/`row_hash` 形成哈希链，并记录档位、切片序号、参数版本、内容
哈希与图谱版本。启动时清理临时文件、校验哈希链、字段完整性与切片文件
内容；断链/字段缺失/文件损坏一律 `E_RECOVERY_INVALID` 中止。已提交切片
以 `(tier,version,slice_index)` 去重，恢复后不重复写入。

## 9. 诊断界面与确定性入口（要求 8）

`gui.py` 提供版本时间轴、切片网格（绿=复用、黄=重算、红=陈旧拒绝）、
回退差异与跨档告警，支持提交、回退、启动与协作式取消。每档独立任务锁，
重复启动返回 `E_BUSY`；取消或异常后释放锁并保留最后已提交状态。
`samplegen.py` 产出 16k/44.1k/48k 与单/双声道样本及固定参数修改+回退
序列，`trajectory.jsonl` 记录版本号、切片序号、失效原因、复用/重算片数与
内容哈希，两次独立运行轨迹逐字节一致。

## 10. 错误码

| 错误码 | 触发场景 |
| --- | --- |
| `E_SOURCE_INVALID` | WAV/帧描述非法或矛盾 |
| `E_SPAN_MISMATCH` | 跨档同片段起止样本不一致 |
| `E_RECOVERY_INVALID` | 清单断链、字段缺失或切片损坏 |
| `E_BUSY` | 同档位重复启动重算任务 |
| `E_STATE_INVALID` | 参数内容非法、回退目标不匹配 |
| `E_NOT_FOUND` | 档位或版本不存在 |

## 11. 验证结果

`QT_QPA_PLATFORM=offscreen pytest -q` 实测 48 项全部通过；CLI 对三种样本
均得到回退哈希一致、`E_SPAN_MISMATCH` 正确定位、恢复清单行数正确，且
轨迹日志跨运行逐字节复现。
