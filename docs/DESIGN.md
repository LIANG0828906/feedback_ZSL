# 非真实感绘制管线设计说明

## 1. 模块总览

| 模块 | 职责 |
| --- | --- |
| `npr/scene.py` | JSON 场景解析、直线/二次贝塞尔（固定 16 段细分）展平、闭合/有限性/分区不重叠校验、分区索引 |
| `npr/params.py` | 三层可序列化参数（frozen dataclass）与因子哈希 |
| `npr/strokes.py` | 轮廓/排线阴影/涂抹三层确定性笔触生成与剔除 |
| `npr/geometry.py` | 弧长采样、线段求交、点到折线距离、凹多边形直线裁剪 |
| `npr/storage.py` | 采样网格路由、批次切分、临时文件 + `os.replace` 原子提交、清单哈希链、恢复与垃圾回收 |
| `npr/pipeline.py` | 因子失效判定、批次复用、协作式取消、轨迹日志（JSONL） |
| `npr/preview.py` | 不可变版本快照、整体发布、`E_STALE_VERSION` 句柄校验 |
| `npr/render.py` | 纯 numpy 离屏光栅化（胶囊笔触 alpha 合成）与 stdlib PNG 写出 |
| `npr/controller.py` | 单任务后台线程、`E_BUSY`、批次边界取消 |
| `npr/viewer.py` | PyQt5 预览窗口，固定 500ms 刷新；GL/平台不可用自动离屏 |
| `npr/samples.py` | PCG64 种子驱动的确定性样本生成器（tiny/medium/large） |
| `npr/cli.py` / `npr/crash_demo.py` | 脚本化回归入口与强制终止/续算演练入口 |

层号固定为 `0=outline`、`1=shadow`、`2=smear`。

## 2. 确定性保证

* 坐标统一量化到 6 位小数（`npr.QUANT_DECIMALS`），序列化采用键排序、无空白的 canonical JSON；
* 随机量全部来自 `numpy.random.Generator(PCG64(seed+salt))`，每层 salt 固定，抖动消费顺序固定；
* 笔触 `id` 按“路径顺序 → 几何顺序”全局连续分配，同参数下逐字节一致；
* 哈希仅覆盖 canonical 内容（SHA-256），轨迹日志只记录结构化字段与内容哈希，不含时间戳/PID/文件大小；
* PNG 通过 `zlib` 固定压缩级别输出，画布哈希等于 RGBA 字节的 SHA-256。

## 3. 三层笔触与剔除闭包

* 轮廓层：沿展平折线按弧长均匀布点，法线方向抖动，记录切向角度；
* 阴影层：按角度/间距生成无限直线，用边交点区间裁剪到分区内部，再按固定笔长切段；
  剔除条件为与任一轮廓边真正相交，或笔触中心到轮廓环距离小于 `cull_margin`，剔除结果仅记录被剔除的笔触编号；
* 涂抹层：场景包围盒上的抖动网格，落在分区内才保留；alpha 由密度半径内阴影笔触数
  线性映射到 `[min_alpha, max_alpha]`，因此阴影密度变化必然传导到涂抹层。

## 4. 因子、失效闭包与批次复用

因子 = 场景几何哈希 + 三层参数哈希。依赖图 `outline → shadow → smear`：

* 场景/轮廓因子变化 → 三层全部重算（阴影剔除闭包 + 涂抹密度闭包）；
* 阴影因子变化 → 阴影 + 涂抹；
* 涂抹因子变化 → 仅涂抹；
* 因子集合无法识别时保守全量重算，并在轨迹 `reason` 中留痕。

笔触按 `id // 48` 切批次，按固定 10 单位网格路由到 `(chunk_x, chunk_y)`。
未受影响层的清单条目（层/批次/分块/内容哈希/因子版本）原样进入新版本，
轨迹同时记录 `recomputed_batches` 与 `reused_batches`。

## 5. 原子提交与恢复

1. 新版本所有分块先写到 `*.tmp` 并 `fsync`，再 `os.replace` 到目标路径；
2. 任一写出失败抛 `E_COMMIT_FAILED`，回滚本次已写文件与临时文件，上一版本清单与分块不动；
3. 全部分块就位后才原子替换 `manifest.json`；清单含父版本号、父清单哈希、条目内容哈希；
4. 旧清单在提交前快照到 `manifests/manifest.vN.json`，形成不可变哈希链；
5. 恢复时自当前清单沿父链逐版校验：清单哈希不符、分块缺失或内容哈希断裂均返回
   `E_RECOVERY_INVALID` 并定位首个断裂层号；
6. 恢复过程清理所有 `*.tmp` 与不属于哈希链版本的分块目录（强制终止遗留物）。

## 6. 预览一致性与并发边界

* 后台线程在独立缓冲完成整版渲染后，通过锁一次性替换 `PreviewService` 当前快照；
* 快照是不可变句柄，发布后旧版本进入 retired 集合，再读取旧句柄即 `E_STALE_VERSION`；
* 同一场景仅允许一个重算任务，重复 `submit` 返回 `E_BUSY`；
* 取消事件在层/批次边界检查，取消或异常不触碰已提交版本，预览仍可读旧快照；
* 强制终止后的续算只信任磁盘分块与清单，内存状态不参与恢复。

## 7. 错误码对照

| 错误码 | 触发点 |
| --- | --- |
| `E_SCENE_INVALID` | 字段缺失、未闭合、坐标非有限、分区重叠（消息含 path 编号） |
| `E_COMMIT_FAILED` | 分块/清单写失败，已回滚，旧版本保留 |
| `E_RECOVERY_INVALID` | 清单版本/哈希链断裂、分块缺失或被篡改（消息含首个断裂层） |
| `E_STALE_VERSION` | 读取已退役快照句柄 |
| `E_BUSY` | 重算任务进行中再次提交 |
