# 设计说明

## 模块边界

| 模块 | 职责 |
| --- | --- |
| `config.py` | 配置字段校验和频段变更识别 |
| `measurement_io.py` | 16-bit PCM、48000 Hz、mono/5.1 声道解析 |
| `geometry.py` | 距离字段、位置欧氏距离和换算依据 |
| `alignment.py` | 互相关到达估计、整样本对齐和置信度 |
| `coupling.py` | 确定性频带滤波、复传递估计和不确定区间 |
| `budget.py` | 路由矩阵、相位残余地板和逐对预算 |
| `phase.py` | 卷绕、跳变、极性候选和群延迟连续性 |
| `calibration.py` | 约束顺序、深度/极性求解和冲突报告 |
| `incremental.py` | 依赖节点和受影响频段集合 |
| `snapshot.py` | 原子提交、哈希校验和恢复 |
| `trace.py` | 无时间戳的确定性 JSONL 轨迹 |
| `engine.py` | 完整链路、缓存、单任务管理和整体发布 |
| `gui.py` | PyQt5 视图和后台工作线程 |

## 缓存键

- 对齐：清单摘要、几何摘要、布局、所有激励和逐对 WAV 内容哈希。
- 耦合：配对键、频段哈希、对齐哈希、估计器版本。
- 路由：频段哈希、该频段全部耦合估计哈希。
- 预算：路由哈希、目标抑制量、深度上限、残余地板。
- 相位：全部耦合估计哈希、相位策略。
- 校准：预算哈希、相位证据哈希、目标、深度上限、增益台阶和残余地板。

内容哈希使用排序键、紧凑分隔符和 UTF-8 规范 JSON 的 SHA-256。浮点在序列化边界统一到 12 位小数，避免平台无关格式差异。

## 保守重算规则

以下情况即使某个频段哈希未变，也不能直接证明安全：

- 频段 ID 集合变化。
- 频段覆盖出现间隙或重叠。
- 估计器版本变化。
- 对齐依据或分量内容变化。

这些情况会加入 `forced_bands`，并在 `forced_reasons` 中记录保守重算原因。

## 发布不变量

- `AnalysisState` 构造完成后不再修改。
- 快照提交成功后才更新管理器发布指针。
- 查询返回同一完整状态对象的引用，不拼接旧路由和新校准。
- 主声道在所有频段的 `gain_db=0`、`polarity=+1`。
- 所有启用校正的深度不超过配置上限。
- 预算和校准都不改写目标抑制量。
