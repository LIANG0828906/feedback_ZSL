# SpectralForge 设计说明

## 1. 模块边界

| 模块 | 职责 |
| --- | --- |
| `internal/domain` | JSON 模型、原始字段检查、数值范围检查、内容/采样/参数哈希 |
| `internal/sample` | 固定种子样本和解析真值生成 |
| `internal/spectral` | 波长重采样、梯形/中点积分、CMF 乘积积分、白点归一 |
| `internal/quant` | 定点量化、逐样本误差、内容+量化签名材质缓存 |
| `internal/shading` | 生成器真值与主渲染共享的纯 BRDF 近似 |
| `internal/geom` | 全局像素中心三角形命中与深度选择 |
| `internal/render` | 分块调度、预算、光栅化、色调映射、接缝检查、检查点主链 |
| `internal/store` | 串行原子写、清单、块文件、提交日志、运行统计 |
| `internal/verify` | 不导入 `internal/render` 的独立重算与差异定位 |
| `internal/web` | 本地页面、参数快照、预览/精确版本隔离 |

## 2. 输入校验

加载顺序是“原始 JSON 对象/数组检查 → 强类型解码 → 数值语义检查”：

1. JSON 语法损坏返回 `E_DECODE`，并带文件/字段位置。
2. 必填字段缺失或数组长度不符返回 `E_SCHEMA`。
3. 数值越界返回 `E_PARA`，包含字段路径、允许范围和实测信息。
4. 基函数系数按 `basis_bits` 和 `basis_signed` 计算闭区间；越界立即失败。
5. 波长必须严格递增，CMF 的 X/Y/Z 和每个光源强度必须与波长逐点等长。
6. 网格声明 `vertex_count`、`material_channels` 必须与顶点和内建五通道材料一致。
7. 色域正反矩阵乘积必须接近单位阵，避免静默输出错误 RGB。

## 3. 光谱积分

样本波长是严格递增的离散表；渲染时在首末波长间重采样：

- `trapezoid`：`N` 个节点，首尾权重为半个步长。
- `midpoint`：`N` 个箱，每箱取中点，权重为步长。

对每个波长节点计算：

```text
radiance(lambda) = light(lambda) * reflectance(lambda) * brdf_factor
XYZ += radiance(lambda) * CMF(lambda) * quadrature_weight
```

渲染器的 `Kernel` 预先计算 `light * basis * CMF * weight`，但不改变逐节点乘积与积分顺序。
最终 XYZ 逐分量除以白点后，用目标色域逆矩阵得到线性 RGB。负值超出 `-1e-7` 返回 `E_GAMUT`。

反射率为：

```text
reflectance(lambda) = sum(fixed_coefficients[i] * basis[i](lambda))
```

系数先按对象声明的定点位深归一化，再按当前量化参数重新定点。

## 4. 材质量化与缓存

量化栅格使用二进制嵌套层级：

- 单位量：`round(v * 2^bits) / 2^bits`
- 有符号基函数系数：按 `2^(bits-1)` 缩放
- 无符号基函数系数：按 `2^bits` 缩放

粗栅格点是细栅格的子集，因此每个样本的绝对误差随位深增加不增；`quantization.json` 逐样本记录 `before`、`after`、`error`，并汇总均值、最大值、RMSE。

材质缓存以对象内容哈希为入口，同时保存量化签名。相同内容哈希在缓存未重置时用不同量化参数访问会返回 `E_QMIX`，不会静默复用。

## 5. 分块与预算

- 块固定 `tile_size`，按行优先编号。
- 每个像素使用全局坐标 `(x+0.5, y+0.5)`，不依赖块内坐标，因此块边界不会产生半像素偏移接缝。
- `max_workers` 限制并行块数；每个工作线程复用一个容量为 `per_thread_pixel_buffer` 的缓冲。
- `queue_budget` 是阻塞队列容量。入队失败时记录 `queue_budget` 等待原因和块号，然后阻塞等待，不会丢块。
- 每个块独立完成深度选择、材质插值、多光源直接光照和 `indirect_bounces` 次间接近似。
- 所有块完成后对相邻块同对象边界做显示亮度跳变检查；超阈值返回 `E_SEAM`，带两侧块号和实测跳变。

## 6. 确定性与调度

块内所有写入只落在该块缓冲，不存在跨块浮点累加；调度顺序和线程标识不参与像素计算。
结果提交顺序固定为块索引序。即使工作线程乱序完成，协调器也只按连续前缀提交，因此全量、实时、恢复三条路径得到相同像素和相同 `commits.log` 序列。

## 7. 版本快照

- `param_version = SHA256(canonical(render_config))`。
- 精确渲染启动时复制当前参数快照，并在整个任务中携带该版本。
- 每个块提交前检查参数、采样、内容版本；混用返回 `E_VER` 并指出两侧版本。
- 预览在显示参数（曝光/曲线/gamma/阈值）单独变化时直接复用线性块结果，只重做显示编码，不重算光谱块。其他参数或采样编辑影响所有光谱块，因此返回全部脏块。
- `render.AffectedTiles` 对场景材质/几何变化按旧、新网格包围盒计算受影响块；背景或尺寸变化返回全屏。

## 8. 检查点协议

检查点目录包含：

```text
manifest.json
tiles/000000.json ...
commits.log
run-stats.json
```

每个块文件包含：

- 块坐标和尺寸
- 线性 RGB 累加缓冲
- 对象 ID 与峰值辐亮度
- 场景内容哈希、光谱采样版本、参数版本
- 完整材质缓存键映射
- 像素 SHA-256 摘要

写文件使用同目录临时文件、`fsync`、`rename`；块提交和提交日志追加由同一互斥锁串行化。恢复只接受从 0 开始连续、摘要和所有版本均匹配的块前缀。任何不匹配都会删除整个检查点目录并全量重算。

非正常终止后，只承诺已持久化块可恢复；不承诺完整退出报告。

## 9. 独立验证器

`internal/verify` 故意不导入 `internal/render`，重新实现：

- 波长重采样和两种积分
- 定点材质量化
- 三角形命中、顶点属性插值
- 光谱 BRDF、间接反弹
- 色调映射、gamma 和显示字节编码

它只读取场景/光谱/参数、持久化块快照、提交日志、运行统计和最终帧。按块比较线性 RGB、对象 ID、峰值辐亮度、块摘要；再比较整帧线性 RGB、显示字节和块摘要列表。首个差异输出块号、像素坐标、字段名、期望值和实测值。报告同时包含主链耗时、验证耗时、比值和逐块等待原因。

## 10. 错误码

| 错误码 | 含义 |
| --- | --- |
| `E_SCHEMA` | 必填字段/数组形状/清单结构缺失 |
| `E_PARA` | 数值越界、坐标范围非法、参数组合非法 |
| `E_DECODE` | 文件不可读或 JSON/检查点损坏 |
| `E_GAMUT` | 线性 RGB 非有限或落入负色域，带像素和通道 |
| `E_QMIX` | 未重置缓存时混用量化签名 |
| `E_VER` | 参数/采样/内容版本混用，带两侧版本 |
| `E_SEAM` | 块边界亮度跳变超阈值，带相邻块和跳变 |
| `E_PAUSED` / `E_CANCELED` | 主动暂停或取消，已提交状态仍可恢复 |

## 11. 测试覆盖

- `domain`：缺失字段、越界、系数位深、波长/CMF 对齐、材质数量、损坏 JSON、真值来源。
- `spectral`：两种积分覆盖区间、直接样本乘积与 Kernel 一致性、重复确定性。
- `quant`：位深单调误差、`E_QMIX`、缓存键内容+量化依赖。
- `render`：三路径一致、预算等待、版本失效、重试一致、预览/精确一致、色域定位、检查点元数据、接缝定位、调度无关像素。
- `store`：并发块写 JSON 完整、参数版本失效、混版本提交拒绝。
- `verify`：正常通过、首个块像素差异、最终显示差异。
- `web`：本地页面、精确渲染、图像端点、独立校验、显示参数预览零块重算。
