# 技术说明与设计决策

## 1. 确定性与可复现

- 样本生成器固定种子 `SEED=20261123`，所有随机数来自
  `numpy.random.default_rng(SEED)`，像素为“渐变 + 有界整数噪声”。
- 管线全程 `float64`，无随机分支、无字典序依赖的数值运算，
  线程仅做数据并行，归并顺序固定为批编号升序，因此并行/串行结果逐像素一致。
- 样本图像使用自定义 `.cimg` 容器（魔数 + JSON 头 + 小端原始像素），
  不引入 Pillow/libpng 等外部解码依赖，损坏样本可精确制造。

## 2. 多版本归一化

解析器 `profile_io.py` 先按版本标签识别版本，再分派到 `_parse_v1/_v2/_v3`，
统一产出 `model.ColorProfile`：

- 版本 1 的三个 colorant 列在解析时转置为行主序 3x3。
- 版本 2 的表格 TRC、可选 3D LUT 与短意图枚举被归一。
- 版本 3 支持参数/表格两种 TRC 与 kebab 意图。
- `label_map` 记录源标签名 -> 内部字段，越界异常直接报源标签名。
- 校验分层：结构/必填问题归 `E_VER`，取值越界归 `E_PARA`。

## 3. TRC 两类表达的数值差异

`trc.py` 中：

- 参数式：gamma 幂函数或 sRGB 分段函数。
- 表格式：编码轴等间距，线性插值反演；编码方向在单调表上反查。

`trc_inversion_difference(param, table)` 在同一 4096 点网格上记录
最大/平均绝对差与最大差位置，生成器把基准值写入 `manifest.json`，
测试以 1e-12 容差复算，保证差异可测且可回归。

## 4. 白点适配与渲染意图

- PCS 参考白点为 D50 XYZ；源/目标白点由 `resolve_white_point` 解析，
  缺省仅使用配置声明默认值并产出 `TraceRecord`。
- Bradford 适配矩阵由锥响应域对角缩放构造。
- 相对比色 = Bradford 适配；绝对比色 = 恒等（保留介质差）；
  感知 = Bradford 适配 + 逐元素 soft-knee 单调收缩，仅压缩超过膝点 0.7
  的正向高亮，保证 `perceptual <= relative` 逐元素成立且差异严格为正。

## 5. 缓存粒度与依赖失效

管线按连续若干行划批，每批保存五个阶段产物。依赖表：

| 编辑参数 | 失效起始阶段 |
| --- | --- |
| TRC 表格/gamma | S1 |
| 矩阵 / 3D LUT | S2 |
| 白点 / 渲染意图 | S3 |

提交取受影响参数中最靠前阶段，失效该批及其下游；未受影响阶段以同一
ndarray 对象复用（测试用 `assertIs` 验证意图切换时 S1/S2 对象身份不变）。

## 6. 原子提交与回滚

`ProfileEditor` 持有工作副本。`commit` 先深拷贝已提交模型快照，再在暂存区
做完整校验（含矩阵可逆性、TRC 表单调性、意图合法性）；任一异常即恢复工作副本
并抛出，已提交模型与 `param_version` 保持不变。校验通过后才一次性替换
`TransformConfig` 引用并递增参数版本。

## 7. 快照完整性

- 每批：`.tmp` 写盘后 `os.replace` 原子落盘，内容哈希取原始字节 SHA-256。
- 清单仅在所有批成功后原子替换；缺清单即视为强杀后的不完整快照。
- 加载校验算法版本、配置版本、参数版本、源哈希与每批哈希；任一失败
  `discard()` 清空全部批，杜绝“部分旧批 + 部分新批”的混用。

## 8. 并发资源边界

- `BoundedBuffer` 以像素数为配额，`acquire` 在配额不足时在条件变量上等待，
  因此背压是阻塞而非丢弃。
- 快照写入在 `BatchExecutor._snapshot_lock` 内进行，保证不交错；
  `commit_sequence` 最终排序为批编号，稳定可断言。
- 单批异常被捕获并记录到 `failed_batches`，其他批状态与结果不受影响，
  可通过 `retry_failed` 重试；引擎门面在调用方需要时统一上抛错误码。

## 9. 已知边界

- 灰度按“三通道等权”进入彩色管线，输出折叠回单通道；RGBA 的 alpha
  做直通与位深重采样，不参与颜色转换。
- 自定义 `.cimg` 为本工作台内部格式，UI 导出同样写该格式；
  如需 PNG/TIFF 可在 `image_io.py` 增加编码器，不影响核心管线。
- 强制终止发生在清单提交前时，按需求不保证完整差异报告，重启后整体重算。
