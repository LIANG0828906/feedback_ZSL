# 确定性样本说明

本目录由 `balance_lab.generator.generate_all()` 生成，固定种子为 `420143 / 730021 / 991337`。重复生成会得到逐字节一致的文件。

| 文件 | 内容 |
|---|---|
| `manifest.json` | 工程清单、文件哈希、默认验收预算、真值计数 |
| `alpha.json` / `beta.json` / `gamma.json` | 三套战斗数值工程 |
| `*.candidates.json` | 每套工程的 7 个候选调整方案 |
| `injection_cases.json` | 工程与运行时异常链路注入清单 |

## 固定点尺度

- 伤害、生命：milli-HP，`1000 = 1 HP`
- 系数、命中波动、候选缩放：basis points，`10000 = 1.0`
- 资源：milli-resource
- 冷却、回合：整数

## 每套工程

- 3 个职业、9 个技能、30 个公式节点
- 6 套配装、6 个场景（4 单挑 + 2 小队）
- 7 个候选方案（基线、爆发、续航、攻击、防御、玻璃大炮、资源）
- 已验证：技能引用、公式 DAG 无环、主配装一一对应

## 真值

- `truth.formula_cases`：9 个技能在指定攻守配装上的精确整数伤害区间。
- `truth.win_rates`：每场景 256 种子基线校准带，带确定性采样前缀容差。
- `truth.thresholds`：每场景攻击/防御关键阈值，按候选有效属性判定。

## 默认验收请求

`manifest.json` 的 `demo_request` 给出每套工程默认目标采样、最小采样和总采样预算。该预算故意不足以覆盖“目标采样 × 全部组合”，用于触发可解释削减与排队。
