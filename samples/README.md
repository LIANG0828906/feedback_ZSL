# Deterministic Sample Set

All files in this directory are produced by:

```bash
python scripts/generate_samples.py --seed 20261123 --output samples
```

The generator uses no external assets. It creates five drawable layers
(`background`, two props, a character, and a character glow child), 18 frames,
and six fixed windows of three frames.

| File | Purpose |
| --- | --- |
| `scene_vpfc1.json` | Flat `vpfc/1` scene, frame-unit time base, global sRGB and global premultiplied alpha |
| `scene_vpfc2.json` | `vpfc/2` scene, tick time base, parent references, per-layer transfer and alpha mode |
| `scene_vpfc3.json` | `vpfc/3` scene, seconds period, nested children, per-layer linear/sRGB and alpha modes |
| `frame_instructions.json` | Per-frame window assignment and six sample pixel coordinates |
| `truth/expected_frames.json` | Independent reference RGBA8 results for all sample pixels |
| `truth/visibility_endpoints.json` | Raw visibility endpoints and parent links |
| `truth/field_mappings.json` | Exact source-path to internal-path mapping truth per version |
| `generator_manifest.json` | SHA-256 of every generated file |

The sample pixel coordinates deliberately cover the background, both props,
the character, and the glow child. The expected RGBA values are generated by a
separate pure-Python reference compositor, not by the production renderer.
