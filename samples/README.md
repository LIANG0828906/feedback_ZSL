# Local deterministic sample

`formation_scene.json` is generated by:

```bash
python -m formation_workbench generate --seed 167 --output samples/formation_scene.json
```

Useful edits for acceptance:

- `(11, 7) + cost`: only `delta` traverses this cell; alpha/bravo/charlie caches reuse.
- `(13, 9) + cost`: `alpha` path is affected; all descendants resmooth and replay.
- `(2, 2) + cost`: no member traverses or searches this cell; all caches reuse.
- `blk-crossing:on`: opens invalidation for members passing through the central closure.

The scene uses four members, a wedge-tree parent relation, fixed-point steps, soft/hard
formation bounds and two blockades (one active, one initially open).
